# Speech datasets for recognition, voice-copy and prosody tests

Scope: datasets of real voice recordings with transcripts that a physical voice simulator
(English, Russian, Hindi, Mandarin) can use to test recognition, re-synthesis and speech modes.
Research date: November 2026. Every licence below was read on the official page, the official
repository, the Zenodo/figshare/Hugging Face API record or the OpenSLR entry named in the row.
Anything not confirmed that way is marked "(unverified)"; unreachable hosts are named in
backticks instead of being linked. No dataset audio was downloaded; only metadata and headers.

## How to read the tables

- **commit** - public domain or CC0 with no extra contract; a small subset may be committed.
- **fetch** - open licence with conditions (attribution, share-alike, notice); download inside
  the CI job, use, discard. Never copy into the repository or into release artefacts.
- **fetch (NC)** - as above, but non-commercial or research-only. Flagged: a public-domain
  project cannot pass such a restriction on, so use only for private measurements.
- **no** - paid, registration, signed agreement, e-mail request, or licence not found.
- "Unit" is the smallest thing a CI job can download without taking the whole corpus.

## Fetch mechanisms that avoid whole-corpus downloads

All of these were exercised during the research (metadata or `HEAD` requests only).

```sh
# 1. Hugging Face datasets-server: N rows (max 100) with text and a signed per-row audio URL.
#    Works without a token for ungated datasets that have a parquet conversion.
curl -s 'https://datasets-server.huggingface.co/rows?dataset=google/fleurs&config=ru_ru&split=validation&offset=0&length=20'
curl -s 'https://datasets-server.huggingface.co/splits?dataset=google/fleurs'   # list configs and splits

# 2. Hugging Face single file from a dataset repository (no archive needed).
curl -sLO 'https://huggingface.co/datasets/AISHELL/AISHELL-3/resolve/main/test/wav/SSB0005/SSB00050353.wav'

# 3. LibriVox API: text source, readers, per-section MP3 URLs and durations.
curl -s 'https://librivox.org/api/feed/audiobooks/?id=353&format=json&extended=1'

# 4. archive.org item metadata (file names, sizes, licence URL); files accept HTTP Range.
curl -s 'https://archive.org/metadata/aesops_fables_russian_0905_librivox'

# 5. Wikimedia Commons: files of a category with licence metadata, or CC0-only search.
curl -s 'https://commons.wikimedia.org/w/api.php?action=query&format=json&generator=categorymembers&gcmtitle=Category:Lingua_Libre_pronunciation-hin&gcmtype=file&gcmlimit=50&prop=imageinfo&iiprop=url%7Cextmetadata'
curl -s 'https://commons.wikimedia.org/w/api.php?action=query&format=json&list=search&srnamespace=6&srlimit=50&srsearch=incategory:%22Lingua_Libre_pronunciation-hin%22%20haswbstatement:P275=Q6938433'

# 6. Take only the first megabytes of a tarball (OpenSLR, GitHub release assets and
#    archive.org answer Range requests; a gzip stream can only be read from its start).
#    tar ends with "Unexpected EOF", which is expected; the members before the cut are intact.
curl -s -r 0-20000000 'https://www.openslr.org/resources/118/GV_Eval_3h.tar.gz' | tar -xz || true
```

- Mechanism 6 was tested on a non-audio archive (first 1.5 MB of the THCHS-30 `resource.tgz`
  listed its leading members). Which utterances come first is decided by the archive order.
- Mechanism 1 fails for script-based datasets (LJ Speech on Hugging Face has no viewer) and
  for gated ones (all AI4Bharat sets) unless a token of an account that accepted the terms is
  supplied as a CI secret.
- Mechanism 5: `P275=Q6938433` is the Wikidata statement "licence = CC0"; the query above
  returned 2,261 hits for Hindi. Always re-read `extmetadata.LicenseShortName` per file.
- Send a descriptive `User-Agent` to Wikimedia and archive.org and cache results in the job;
  Wikimedia answered HTTP 429 when queried quickly.
