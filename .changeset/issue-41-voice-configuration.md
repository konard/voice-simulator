Expand the voice configuration (issue 41). `HEAD_PARAMETERS` has 137 entries in six groups (`HEAD_GROUPS`: `anatomy`, `folds`, `breathing`, `articulation`, `expression`, `microphone`; the old `mouth`, `face`, `voice`, `source`, `prosody` and `acoustics` are gone), each with a unit, a range, a default, a `source` and an `effect` (`{measure, sign}`, the measured direction in which the value moves the sound), and `advanced` for the values the editor hides by default. The new values make the constants of the folds, the breathing, the walls, the teeth, the nose, the articulator speeds, the duration rules, the microphone and the room part of the head; their defaults keep the old sound. Voice files: `loadVoice()`, `saveVoice()`, `voiceSchema()`, `VOICE_FORMAT` and `VOICE_VERSION`, with `schemas/voice.schema.json` and the generated `docs/VOICE-PARAMETERS.md`. New presets `child5`, `teenMale`, `teenFemale`, `elderlyMale`, `elderlyFemale`, `bass`, `baritone`, `tenor`, `alto`, `mezzo` and `soprano`. CLI: `--voice <file>`, `head --voice-file [--full]` and `voice check <file>`. The app editor shows one section per group, "Show all parameters", "Import voice" and "Export voice". The Rust core reads the new values and its 3D solver gets the moving glottis, the larynx extension and the pouch places of issue 40.
